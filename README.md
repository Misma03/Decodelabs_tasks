## Projects Overview

| Project | Focus | Tools |
|---|---|---|
| 1. Data Cleaning | Handling missing values, duplicates, and formatting | Python, pandas |
| 2. Exploratory Data Analysis | Statistics, trends, outliers, correlations | Python, pandas, seaborn |
| 3. SQL Data Analysis | Querying, aggregation, business reporting | Microsoft SQL Server |
| 4. Data Visualization | Charts and stakeholder ready visuals | Python, matplotlib, seaborn |

## Project 1: Data Cleaning and Preparation
Cleaned a raw 1200 row e-commerce order dataset by handling missing values, removing duplicates, and fixing data formats. Produced a reliable cleaned dataset used as the foundation for every other project.
[View Project 1](https://github.com/Misma03/Task-1-Misma-Yaseen)

## Project 2: Exploratory Data Analysis
Explored the cleaned dataset to uncover patterns, calculate descriptive statistics, detect outliers using the IQR method, and analyze correlations between order value, quantity, and unit price.
[View Project 2](https://github.com/Misma03/Task-2-Misma-Yaseen)

## Project 3: SQL Data Analysis
Wrote 20 T-SQL queries in Microsoft SQL Server covering filtering, grouping, aggregation, HAVING clauses, and window functions to extract business insights such as top products, top customers, and monthly growth rate.
[View Project 3](https://github.com/Misma03/Task-3-Misma-Yaseen)

## Project 4: Data Visualization
Built 10 charts including bar charts, pie charts, a line chart, histogram, boxplot, and correlation heatmap to communicate revenue trends, order status, and customer behavior visually.
[View Project 4](https://github.com/Misma03/Task-4-Misma-Yaseen)

## Key Skills Demonstrated
Data cleaning, exploratory data analysis, SQL querying and aggregation, data visualization, and business insight reporting using Python and Microsoft SQL Server.
